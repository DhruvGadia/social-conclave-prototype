# Project credits and licensing scope

## Creator and development

**Social Conclave 10 — Time for Impact** is a website prototype created and developed by **[Dhruv Gadia](https://github.com/DhruvGadia)**.

The project includes the Impact Compass, saved interests in My Conclave, a personal intention planner, an edition explorer, responsive layouts and a GitHub Pages deployment workflow. Credit for developing this website belongs to Dhruv; the author of the reference project is not being presented as a collaborator or developer of this version.

## Design reference

The project's visual direction was informed by the earlier [Social Conclave — Interactive UI/UX Design Prototype](https://github.com/4aru5h/social-conclave-design-prototype), published by **Aarush Sharma**. References include its Social Conclave identity and blue visual palette. Using a design reference is different from collaborating on the current implementation.
